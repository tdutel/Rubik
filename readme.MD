Le superflip est une configuration particulière du Rubik's Cube où toutes les arêtes sont inversées, mais toutes les coins sont dans leur position correcte. C'est un exemple classique utilisé pour démontrer la complexité de la résolution du Rubik's Cube.

God's Number est le nombre maximum de mouvements nécessaires pour résoudre n'importe quelle configuration du Rubik's Cube en utilisant la méthode la plus efficace possible. = 20 coups.

God's Algorithm : patern hypothetique qui permettrait de resoudre n'importe quel rubik de nimporte quelle configuration en un nombre
